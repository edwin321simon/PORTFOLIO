# Edwin Simon - Futuristic Cloud & Cyber Systems Portfolio

An ultra-futuristic, cyber-themed portfolio web app engineered for Edwin Simon — Microsoft Certified Azure Administrator (AZ-104 & AZ-900), Cloud Systems Architect, and Full-Stack Developer.

## Features
- **Vercel Edge Ready**: Single-page static architecture with zero build step dependencies.
- **Interactive Three.js 3D Background**: Real-time particle matrix canvas with cursor tracking.
- **Synthesized Cyber Audio FX**: Web Audio API sound generator for clicks, whooshes, and chimes.
- **Live Interactive CLI Terminal**: Interactive shell supporting `bio`, `skills`, `projects`, `certs`, `azure`, `ping`, and `clear`.
- **System Architecture Deep Dives**: Modal dialogues for Athlete Forge, PGAS Accommodation Hub, and Azure Cyber Shield.
- **Zero-Trust Telemetry & Verification**: Live node latency ping, certified credentials timeline, and copy-to-clipboard contact vectors.

## Deploying to Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` inside this directory, or drag and drop the folder into the [Vercel Dashboard](https://vercel.com/new).
